Self-hosted Obsidian Sync with CouchDB

June 19, 2026

I’ve been using this setup for a few hours. Already got a couple merge conflicts, which aren’t fun. Might need to tweak some settings. 🤔 Overall, I’m thrilled it’s working.

Obsidian-Livesync (officially known as Self-hosted LiveSync) is a community-developed plugin that runs on all Obsidian-compatible platforms. It syncs your vault across devices without paying for the Obsidian Sync subscription.

Supported platforms:

  • Desktop: Windows, macOS, and Linux
  • Mobile: iOS and Android

It connects your devices to your own self-hosted database (CouchDB or S3-compatible storage), or uses experimental peer-to-peer WebRTC.

Database Configuration

I chose CouchDB. Here’s the Docker Compose setup:

services:
  couchdb:
    image: couchdb:3
    container_name: obsidian-livesync-db
    restart: unless-stopped
    environment:
      - COUCHDB_USER=admin
      - COUCHDB_PASSWORD=your_secure_password_here
      - TZ=America/New_York
    user: "1000:1000"
    ports:
      - "5984:5984"
    volumes:
      - /your/path/to/obsidian-livesync/data:/opt/couchdb/data
      - /your/path/to/obsidian-livesync/etc:/opt/couchdb/etc/local.d

Replace your_secure_password_here with a strong password — you’ll need it in the plugin config later. Adjust the volume paths to wherever you want CouchDB data stored. Port 5984 exposes CouchDB to the network; lock it down with a firewall or put it behind a VPN/reverse proxy.

CouchDB First-Time Setup

CouchDB needs Single Node Mode and open CORS permissions so Obsidian can talk to it.

  1. Open http://<your server>:5984/_utils/ in a browser.
  2. Log in with your admin credentials.
  3. Go to Setup → Configure as Single Node → confirm your password.
  4. Go to Databases → Create Database → name it obsidian (Non-partitioned).
  5. Go to Settings → CORS → enable it, set Allowed Origins to * (or app://obsidian.md and capacitor://localhost).

Reverse Proxy or VPN

Mobile devices require HTTPS. I used Tailscale with Tailscale serve:

tailscale serve --service=svc:obsidian-livesync-db --https=443 http://localhost:5984

Use whatever method you prefer (nginx, Tailscale, etc.) to put HTTPS in front of CouchDB.

Plugin Configuration

Configure on Desktop first, then use the QR code for mobile devices.

⚠️ Warning

Back up your vault before setting up the plugin. Misconfiguration can cause note loss or corruption across synced devices.

  1. Open Obsidian Settings → Community Plugins.
  2. Enable Community Plugins (restart if needed).
  3. Browse → Search for “Self-hosted LiveSync” → Install → Enable → Open Options.

In the LiveSync settings, click the Satellite 🛰️ icon (Remote Server/Customization tab). Use the manual setup wizard rather than Quick Setup.

Choose your encryption preferences. The passphrase here should be different from your CouchDB admin password.

Select CouchDB as the database type.

Fill in the parameters:

FieldValue
Remote TypeCouchDB
URIhttps://<your server>:5984
Usernameadmin
Password(the password from your docker-compose)
Database nameobsidian

Hit Test Settings and Continue — everything should light up green. Once connected, you can generate a Setup URI or QR code from the same settings to provision other devices.

Sync Settings

Syncing won’t start until you configure the sync tab. I went with on events and enabled every event type — it’s less battery-intensive than polling and works intuitively across devices.
