Stonks Allocation Calculator — Build & Deploy

June 19, 2026
react typescript tool

Built and deployed the Stonks Allocation Calculator — a React + TypeScript SPA for managing portfolio allocations.

It supports multiple sessions (portfolios), tracking cash on hand, and calculating how much to buy or sell for each asset to reach your desired allocation. Data persists in localStorage with import/export via JSON backup file. Includes a dark/light/system theme toggle.

Built with Vite, React 19, and TypeScript 6.
